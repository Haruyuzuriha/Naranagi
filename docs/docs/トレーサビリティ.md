## 5. 設計要素と要件の対応確認

### 確認基準

* [ ] すべての必須機能要件が設計に対応付けられている
* [ ] すべての必須非機能要件が設計に対応付けられている
* [ ] 設計上の主要コンポーネントに対応する要件が存在する
* [ ] 対象外機能が明確になっている
* [ ] 要件変更時に対応する設計箇所を特定できる
