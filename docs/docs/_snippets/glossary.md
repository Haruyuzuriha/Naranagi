*[F-01]: F-01 — PDF描画・書き込み。PDF上に自由に描画・書き込みができる機能
*[F-02]: F-02 — 統合ノート機能。同一ウィンドウ内で文章としてのノートを記述できる機能
*[F-03]: F-03 — テキストブックマーク。PDF内のテキストと対応するノートをシームレスに往復できる機能
*[F-04]: F-04 — AIルックアップ。テキスト選択をトリガーに、語彙・専門用語・語源に関する質問へスコープを限定したAI検索機能
*[F-05]: F-05 — 個人辞書。本を横断してアーカイブ単語を蓄積する内蔵辞書機能

*[N-01]: N-01 — プラットフォーム。PC専用アプリとし、モバイル・Web版は非対応とする要件
*[N-02]: N-02 — オフライン動作。AI機能以外はオフラインでも動作することを求める要件
*[N-03]: N-03 — 実装言語。全てJavaで実装することを定める要件
*[N-04]: N-04 — 開発体制。一人開発によるオープンソースプロジェクトであることを定める要件
*[N-05]: N-05 — 品質方針。早さより正しさを優先する方針を定める要件
*[N-06]: N-06 — データベース。SQLiteによるハイブリッド構成(本ごとファイル + 横断共有ファイル)を定める要件

*[ADR-001]: ADR-001 — データベースにSQLiteのハイブリッド構成を採用する設計判断
*[ADR-002]: ADR-002 — 実装言語にJavaを全面採用する設計判断
*[ADR-003]: ADR-003 — OCR対応を見送り、電子データPDFに限定する設計判断
*[ADR-004]: ADR-004 — AI機能を既存オープンモデルのファインチューニング/プロンプト制約で実現する設計判断
*[ADR-005]: ADR-005 — AIルックアップの対象を語彙・専門用語・語源に限定する設計判断
