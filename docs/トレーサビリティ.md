## 3. 逆方向トレーサビリティ {: #reverse-traceability }

設計上存在する主要なコンポーネントについて、それを必要とする要件を確認する。

| 設計要素             | 対応要件                    | 備考                                      |
| ---------------- | ----------------------- | --------------------------------------- |
| 注釈エンジン           | F-01, F-02, F-03        | PDF描画・ノート・テキストブックマークを統合管理               |
| AIルックアップエンジン     | F-04                    | 推奨要件・リリース前最終実装項目(未実装のままv1リリース時はv1.1扱い) |
| 辞書エンジン           | F-05, N-06              | 本を横断した共有SQLiteファイルとして実現                 |
| データ永続化層          | N-06                    | 本ごとファイル + 横断共有ファイルのハイブリッド構成             |
